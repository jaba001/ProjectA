# 검수 목록

사용자가 직접 실행해 확인할 항목만 둔다. 에이전트는 컴파일·정적 검사까지 수행하며 이 목록의 항목을 완료로 표시하지 않는다. 확인 결과를 알려주면 해당 항목을 삭제하고 결과는 커밋 본문에 남긴다. 문제가 있으면 항목 아래에 증상을 적어 두면 된다.

## 1 ROG 방어구 시범 착용 (`3e54746e`)

디버그 전투에서 아군을 두 명 추가하면 남자·여자 몸체가 번갈아 나온다. 장비 목록에서 `획득 + 갑옷/장갑/액세서리 장착`을 누른다.

- [ ] 로브 2종(수련생의 로브·방랑 학자의 로브)이 남녀 몸체를 뚫거나 떠 보이지 않는다.
- [ ] 장갑 2종(가죽 장갑·철판 장갑)이 손 모양과 맞는다.
- [ ] 망토 2종(여행자의 망토·붉은 기사단 망토)의 천 시뮬레이션이 자연스럽고 몸을 뚫지 않는다.
- [ ] 이동·공격·피격 애니메이션과 사망 래그돌에서 의상이 몸체를 따라간다.
- [ ] 일반 Run 장비창에 목걸이·반지 대신 액세서리 1칸이 보이고 기존 무기 장착·해제가 그대로 동작한다.

## 2 투사체 발사점과 전투장 바닥 (`9381071a`)

- [ ] 투사체가 골반이 아니라 손 높이에서 발사되어 보인다.
- [ ] 통합 Gameplay의 하·중·상 난이도 전투장 바닥이 회색 체크무늬 대신 석조 등 해당 환경으로 보인다.
- [ ] 전투가 끝난 뒤 미로·다음 화면의 표시가 원래대로 돌아온다.

## 3 인카운터 미로 Blueprint (`33434df2`)

- [ ] 공통 `BP_EncounterMaze_V7`에서 벽이 뚫리거나 빠진 곳이 없다.

## 4 공격 숄더뷰 거리와 전환 시점

- [ ] 숄더뷰의 카메라 거리와 구도가 적절하다.
- [ ] 준비 완료 직후에는 전술뷰가 유지되고, 내 캐릭터가 공격하러 움직이거나 시전을 시작할 때 숄더뷰로 바뀐다. 시작 지연이 긴 캐릭터도 차례가 오기 전에는 전환되지 않는다.
- [ ] 빙결·스턴으로 행동이 취소되거나 스킬 없이 준비한 라운드에는 숄더뷰로 바뀌지 않는다.

## 5 근접 공격 숄더뷰 튐

- [ ] 근접 캐릭터가 다른 유닛 옆을 지나 공격하러 갈 때 카메라가 순간적으로 당겨지지 않는다.
- [ ] 벽·장식 근처에서는 여전히 카메라가 벽을 뚫지 않고 앞으로 당겨진다.

## 6 상점 퇴장 후 이전 상점 화면 깜빡임

- [ ] 미로 상점에서 나가기 후 다음 선택지가 뜰 때 이전 상점 창이 보이지 않는다.
- [ ] 상점 진입·선택지·지도 화면 전환이 끊기거나 비어 보이지 않는다.
- [ ] 다음 전투의 계획 화면이 열릴 때 이전 전투 화면이, 다음 결과 화면이 열릴 때 이전 결과 화면이 비쳐 보이지 않는다.
- [ ] 메인 메뉴 화면 전환(새 게임·옵션·백과사전 등)에서 이전 화면이 겹쳐 보이지 않는다. 교차 페이드가 사라져 즉시 바뀐다.

## 7 전투 직전 프레임 드랍

- [ ] PvE·PvP 전투 직전(문을 지나 전장으로 넘어갈 때) 화면이 멈추는 느낌이 줄었다. 에디터 PIE는 Niagara 셰이더 컴파일 대기가 남을 수 있으므로 Standalone 또는 패키지 실행으로 비교한다.
- [ ] 전투 시작 후 첫 스킬 이펙트·사운드가 정상 재생된다.

## 8 힘·민첩·지능 재도입

- [ ] 캐릭터 생성 화면에 직업별 힘·민첩·지능이 보인다(전사 10/5/1, 마법사 1/5/10, 궁수 5/7/4, 도적 5/10/1).
- [ ] 전사·도적의 근접 공격과 마법사의 지팡이 스킬 피해가 힘·지능만큼 늘었고, 활·회복·보호막·상태이상 피해는 그대로다.
- [ ] 속도 차 1당 시작 지연 1초가 적용되어 민첩 5인 전사·마법사가 도적보다 5초 늦게 행동하고, 느린 몬스터의 대기 시간이 체감상 과하지 않은지 확인한다.
- [ ] 전투 중 체크포인트 복구와 이어하기 후에도 같은 피해가 나온다.

## 10 방패 상인 손잡이 정렬

- [ ] 방패 태그 상점의 기사가 뒤쪽 손잡이를 왼손으로 잡고 방패가 허리 앞에 눕거나 팔을 관통하지 않는다. 대기 애니메이션 중에도 손과 전완을 따라간다.

수정: 메시 중심 대신 실제 뒤쪽 손잡이를 기준으로 위치를 맞추고 반대편 끈을 전완 방향에 정렬했다. 원본 에셋은 유지하며 `DA_EncounterStageVisuals`의 Warden 소품 변환으로 저장했다. 수정 전후 에디터 렌더를 비교했으며 실제 플레이의 대기 애니메이션 전 구간은 사용자 확인이 필요하다.

## 11 NPC 한글 표지판

- [ ] NPC 상점·부활소의 한글 표지판이 사각형 글리프 없이 표시되고 긴 제목이 표지판 안에 들어간다. 환경 전용 회복의 샘물에는 표지판이 나타나지 않는다.

수정: 기본 TextRender 대신 편집 가능한 `WBP_EncounterSign`과 런타임 글리프 렌더러를 연결했다. 한글 표지판 텍스처에서 `방패 태그별 상점`, 실제 PIE 상점 화면에서 `흰색 등급 상점`의 정상 출력을 확인했다. 관련 회귀 검사 7건을 통과했다. 전체 NPC·영문 제목·패키지 실행은 사용자 확인이 필요하다.

## 13 근접 공격 전열 보호

- [ ] 양 진영에서 같은 줄의 전열에 생존 유닛이 있으면 후열 적에게 근접 스킬을 예약할 수 없고, 원거리·마법 스킬은 예약할 수 있다.
- [ ] 전열 사망·확정 이동·디버그 부활 후 후열 보호 표시와 선택 가능 여부가 갱신된다. 예약만 한 이동은 확정 전 보호를 바꾸지 않는다.
- [ ] 적 AI와 대상 사망 후 근접 재선택은 보호되지 않은 적을 고르며, 전열 보호가 범위·충돌 피격 면역으로 적용되지 않는다.

## 14 근접·원거리 초기 배치

- [ ] 전사·도적 등 근접 장비 캐릭터는 1열, 활·석궁·지팡이·마법서 장비 캐릭터는 2열에 배치되며 기본 맨손 스킬이 원거리 배치를 방해하지 않는다.
- [ ] PvE 적도 실제 스킬 태그에 맞는 열에서 시작하고 빈 슬롯·사망 멤버가 있어도 중복 배치되지 않는다. 선호 열이 가득 차면 다른 열의 빈칸을 사용한다.
- [ ] 다음 전투에서는 변경한 장비로 열을 다시 선택하며, 상대 Snapshot의 저장 배치와 전투 체크포인트 복구 위치는 그대로 유지된다.

## 15 AI 장비 스킬 우선 사용

- [ ] 아군 AI와 상대 Snapshot AI가 비무장 공격보다 장착한 다른 스킬을 먼저 사용한다. 일반 스킬이 여러 개면 기존 장착 순서를 유지한다.
- [ ] 다른 스킬의 AP가 부족하거나 유효 대상·태그 조건이 맞지 않으면 다음 스킬을 검토하고, 모두 사용할 수 없을 때 비무장 공격을 사용한다. 비무장 공격만 가진 AI도 계속 공격한다.
- [ ] 저장 복구 후에도 다음 라운드부터 같은 우선순위를 사용하며, 복구된 확정 명령은 바뀌지 않는다.

## 19 단검 쌍수 이중타격

- [ ] 전투·상점·인벤토리에서 기본 근접 스킬이 타격으로 표시되며 기존 저장의 스킬 식별자·AP·피해·모션은 유지된다.
- [ ] 새 Run에서 도적을 생성하면 단검 2개가 양손에 각각 장착되고 첫 전투부터 이중타격을 사용할 수 있다.
- [ ] 상점·인벤토리의 단검에 기본 스킬 이중타격이 표시된다. 일반 Run과 DebugCombat에서 단검 하나면 전투 목록에 비활성화 상태로 표시되고 쌍수 단검 조건을 안내한다. 두 번째 단검을 장착하면 활성화되고 하나를 해제하거나 방패·검으로 바꾸면 다시 비활성화된다. 마지막 단검 해제 시 목록에서 제거된다. 기존 저장은 장비를 한 번 변경한 뒤 확인한다.
- [ ] 이중타격이 기본 `MeleeAttack`의 좌우 반전본 → 원본 순서로 보이며 왼손·오른손이 한 번씩 별도로 적중한다. 기본 타격과 같은 AP를 한 번만 소비하고, 피해는 현재 무기 10 + 10에 타격별 능력치 보정을 적용한다. 일반 쌍수 타격은 평균 10에 보정 1회를 적용한다.
- [ ] 이중타격이 첫 타격 뒤 복귀를 기다리지 않고 약 0.4초 간격으로 이어지며 연결부에서 몸체가 튀거나 멈추지 않는다. 왼손·오른손의 피해 시점이 모션과 일치한다.
- [ ] 첫 타격에 대상이 죽거나 빗나가도 타격을 중복 실행하지 않고 복귀한다. 벽 차단·시전자 사망·저장 후 Continue에서도 장착 조건과 AP·피해가 유지된다.

## 20 DebugCombat 초기화 복구

- [ ] 전사·마법사·궁수·도적 추가 및 전투 재시작 후에도 조작할 수 있고, 외형 카탈로그가 없는 캐릭터는 클래스의 기본 몸체를 유지한다.

## 21 스킬 단일·범위 표시와 VFX 근접 판정

- [ ] 전투 카드·스킬 상점·인벤토리·백과사전에 단일 대상·범위가 표시되고 연쇄에는 최대 대상 수가 표시된다. 타격·이중타격·일반 투사체는 단일, 참격·공격 장판은 범위로 표시된다. 단일 대상 제한이 있는 회복·보호막은 외형과 무관하게 단일로 표시된다.
- [ ] 도끼·곡검·발도·낫 참격의 VFX 범위 안에 여러 적이 있으면 각각 한 번 피해를 받고 범위 밖과 벽 뒤 적은 피해를 받지 않는다. 애니메이션만으로 추가 피해를 주지 않고 타격·이중타격은 기존 단일 판정을 유지한다.
