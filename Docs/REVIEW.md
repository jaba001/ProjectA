## 15 AI 장비 스킬 우선 사용

- [ ] 아군 AI와 상대 Snapshot AI가 비무장 공격보다 장착한 다른 스킬을 먼저 사용한다. 일반 스킬이 여러 개면 기존 장착 순서를 유지한다.
- [ ] 다른 스킬의 AP가 부족하거나 유효 대상·태그 조건이 맞지 않으면 다음 스킬을 검토하고, 모두 사용할 수 없을 때 비무장 공격을 사용한다. 비무장 공격만 가진 AI도 계속 공격한다.
- [ ] 저장 복구 후에도 다음 라운드부터 같은 우선순위를 사용하며, 복구된 확정 명령은 바뀌지 않는다.

## 16 마법 스킬 캐스팅 시간

- [ ] 새 Run에서 지팡이·마법서의 공격·치유 스킬이 시전을 시작한 뒤 1초가 지나 발동하며 근접·활·석궁·방패 스킬의 준비 시간은 기존과 같다. 투사체 비행 및 발동 후 판정 대기 시간은 별도다.
- [ ] 새 Run 저장·복구 후에도 해당 스킬의 1초 준비 시간이 유지되고 기존 Run의 저장된 준비 시간은 바뀌지 않는다.


## 17 프로젝트 리소스 Assets 폴더

- [ ] Content Browser의 `User_JeHoon` 바로 아래에 `Assets`·`Blueprint`·`LEVEL`·`Localization`·`UI`이 표시되고 리소스의 팩별 하위 구조가 `Assets` 안에 유지된다.
- [ ] 기존 맵에서 캐릭터·몬스터·의상·공격 애니메이션·환경 재질이 정상 표시된다.
- [ ] 정리 전 저장의 이어하기에서 장비·외형·몬스터 및 전투 체크포인트의 리소스를 불러올 수 있다.


## 18 메뉴 검증 위젯 위치

- [ ] 검증용 메뉴 위젯 3종이 `UI/Validation/T12`에 표시되고 `User_JeHoon` 바로 아래의 `Validation` 폴더가 제거되었다.
- [ ] 일반 게임 메뉴와 캐릭터 생성 화면의 배치·표시·동작은 기존과 같다. 선택적인 T12 생성본 자동화 검사는 사용자 실행 시 새 경로를 사용한다.

## 19 단검 쌍수 이중타격

- [ ] 전투·상점·인벤토리에서 기본 근접 스킬이 타격으로 표시되며 기존 저장의 스킬 식별자·AP·피해·모션은 유지된다.
- [ ] 새 Run에서 도적을 생성하면 단검 2개가 양손에 각각 장착되고 첫 전투부터 이중타격을 사용할 수 있다.
- [ ] 상점·인벤토리의 단검에 기본 스킬 이중타격이 표시된다. 일반 Run과 DebugCombat에서 단검 하나면 전투 목록에 비활성화 상태로 표시되고 쌍수 단검 조건을 안내한다. 두 번째 단검을 장착하면 활성화되고 하나를 해제하거나 방패·검으로 바꾸면 다시 비활성화된다. 마지막 단검 해제 시 목록에서 제거된다. 기존 저장은 장비를 한 번 변경한 뒤 확인한다.
- [ ] 이중타격이 기본 `MeleeAttack`의 좌우 반전본 → 원본 순서로 보이며 왼손·오른손이 한 번씩 별도로 적중한다. 기본 타격과 같은 AP를 한 번만 소비하고, 피해는 현재 무기 10 + 10에 타격별 능력치 보정을 적용한다. 일반 쌍수 타격은 평균 10에 보정 1회를 적용한다.
- [ ] 이중타격이 첫 타격 뒤 복귀를 기다리지 않고 약 0.4초 간격으로 이어지며 연결부에서 몸체가 튀거나 멈추지 않는다. 왼손·오른손의 피해 시점이 모션과 일치한다.
- [ ] 첫 타격에 대상이 죽거나 빗나가도 타격을 중복 실행하지 않고 복귀한다. 벽 차단·시전자 사망·저장 후 Continue에서도 장착 조건과 AP·피해가 유지된다.

## 20 DebugCombat 초기화 복구

- [ ] 전사·마법사·궁수·도적 추가 및 전투 재시작 후에도 조작할 수 있고, 외형 카탈로그가 없는 캐릭터는 클래스의 기본 몸체를 유지한다.

## 21 스킬 단일·범위 표시와 VFX 근접 판정

- [ ] 전투 카드·스킬 상점·인벤토리·백과사전에 단일 대상·범위가 표시되고 연쇄에는 최대 대상 수가 표시된다. 타격·이중타격·일반 투사체는 단일, 참격·공격 장판은 범위로 표시된다. 단일 대상 제한이 있는 회복·보호막은 외형과 무관하게 단일로 표시된다.
- [ ] 도끼·곡검·발도·낫 참격의 VFX 범위 안에 여러 적이 있으면 각각 한 번 피해를 받고 범위 밖과 벽 뒤 적은 피해를 받지 않는다. 애니메이션만으로 추가 피해를 주지 않고 타격·이중타격은 기존 단일 판정을 유지한다.

## 22 타격·이중타격 에셋 이름 변경

- [ ] 전사 시작 무기와 쌍수 단검의 타격·이중타격이 평소처럼 표시되고 사용되며 몽타주가 재생된다.
- [ ] 이름 변경 전에 만든 저장을 이어 해도 Run과 준비 완료 체크포인트가 복구되고 예약한 타격·이중타격 명령이 유지된다.
- [ ] 영어 표시는 번역 키 이동 전까지 한국어 원문으로 보일 수 있으며 이 항목의 실패로 보지 않는다.

수정: 옛 경로와 스킬 ID를 리다이렉트로 새 이름에 연결했다. 옛 경로 5건의 로드와 `DoubleStrike` 에셋 검사는 통과했으며 저장 파일 복구와 실제 플레이는 확인하지 않았다.
