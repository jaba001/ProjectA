- [ ] 전투·상점·인벤토리에서 기본 근접 스킬이 타격으로 표시되며 기존 저장의 스킬 식별자·AP·피해·모션은 유지된다.

- [ ] 첫 타격에 대상이 죽거나 빗나가도 타격을 중복 실행하지 않고 복귀한다. 벽 차단·시전자 사망·저장 후 Continue에서도 장착 조건과 AP·피해가 유지된다.

- [ ] 도끼·곡검·발도·낫 참격의 VFX 범위 안에 여러 적이 있으면 각각 한 번 피해를 받고 범위 밖과 벽 뒤 적은 피해를 받지 않는다. 애니메이션만으로 추가 피해를 주지 않고 타격·이중타격은 기존 단일 판정을 유지한다.

## 22 타격·이중타격 에셋 이름 변경

- [ ] 전사 시작 무기와 쌍수 단검의 타격·이중타격이 평소처럼 표시되고 사용되며 몽타주가 재생된다.
- [ ] 이름 변경 전에 만든 저장을 이어 해도 Run과 준비 완료 체크포인트가 복구되고 예약한 타격·이중타격 명령이 유지된다.
- [ ] 영어 표시는 번역 키 이동 전까지 한국어 원문으로 보일 수 있으며 이 항목의 실패로 보지 않는다.

## 23 일반 활과 화살통

- [ ] 새 일반 Run에서 궁수의 활은 주 손만 차지하고 일반 화살통은 보조 손에 장착된다. 사격 중 왼손 활 그립과 등 화살통의 위치가 자연스럽다.
- [ ] 사격은 AP 1을 사용한다. 명중하거나 벽에 막혀도 행동과 화살 판정이 끝날 때 탄약을 1발씩 차감하며 0발이면 사격을 선택할 수 없다.
- [ ] 전투 중 이어하기로 남은 탄약을 복원하고 다음 새 전투에서 3발로 채운다. 변경 전에 만든 Run의 활은 저장된 장착과 스킬을 유지한다.

## 24 방패 돌진 접근 동작

디버그 전투에서 전사에게 `방패 돌진` 스킬을 추가하고 적을 대상으로 사용한다. 위력 50은 임시값이며 양손 방패 장착은 아직 없다.

- [ ] 접근하는 동안 공통 달리기 대신 방패를 앞세운 돌진 자세가 보이고, 몸이 캡슐에서 앞으로 미끄러져 나가지 않는다.
- [ ] 도착하면 방패를 들어 올리는 충돌 동작으로 자연스럽게 바뀌고 0.17초 무렵 피해가 들어간 뒤 복귀한다.
- [ ] 장착한 방패가 돌진 자세의 왼손 위치에서 어색하게 꺾이거나 팔을 관통하지 않는다.
- [ ] 돌진과 복귀 속도가 체감상 너무 빠르지 않고, 보폭과 이동 속도가 맞아 보인다.
- [ ] 접근 중 대상이 죽거나 행동이 취소되면 돌진 자세가 남지 않고 원래 동작으로 돌아온다.
- [ ] 다른 근접 스킬의 접근 달리기는 이전과 같다.
