# 검수 목록

사용자가 직접 실행해 확인할 항목만 둔다. 에이전트는 컴파일·정적 검사까지 수행하며 이 목록의 항목을 완료로 표시하지 않는다. 확인 결과를 알려주면 해당 항목을 삭제하고 결과는 커밋 본문에 남긴다. 문제가 있으면 항목 아래에 증상을 적어 두면 된다.

## 1 ROG 방어구 시범 착용 (`3e54746e`)

디버그 전투에서 아군을 두 명 추가하면 남자·여자 몸체가 번갈아 나온다. 장비 목록에서 `획득 + 갑옷/장갑/액세서리 장착`을 누른다.

- [ ] 로브 2종(수련생의 로브·방랑 학자의 로브)이 남녀 몸체를 뚫거나 떠 보이지 않는다.
- [ ] 장갑 2종(가죽 장갑·철판 장갑)이 손 모양과 맞는다.
- [ ] 망토 2종(여행자의 망토·붉은 기사단 망토)의 천 시뮬레이션이 자연스럽고 몸을 뚫지 않는다.
- [ ] 이동·공격·피격 애니메이션과 사망 래그돌에서 의상이 몸체를 따라간다.
- [ ] 일반 Run 장비창에 목걸이·반지 대신 액세서리 1칸이 보이고 기존 무기 장착·해제가 그대로 동작한다.

## 2 투사체 발사점과 전투장 바닥 (`9381071a`)

- [ ] 투사체가 골반이 아니라 손 높이에서 발사되어 보인다.
- [ ] 통합 Gameplay의 하·중·상 난이도 전투장 바닥이 회색 체크무늬 대신 석조 등 해당 환경으로 보인다.
- [ ] 전투가 끝난 뒤 미로·다음 화면의 표시가 원래대로 돌아온다.

## 3 인카운터 미로 Blueprint (`33434df2`)

- [ ] 공통 `BP_EncounterMaze_V7`에서 벽이 뚫리거나 빠진 곳이 없다.

## 4 공격 숄더뷰 거리 (`fc927773`)

- [ ] 준비 확정 후 숄더뷰의 카메라 거리와 구도가 적절하다.

## 5 근접 공격 숄더뷰 튐

- [ ] 근접 캐릭터가 다른 유닛 옆을 지나 공격하러 갈 때 카메라가 순간적으로 당겨지지 않는다.
- [ ] 벽·장식 근처에서는 여전히 카메라가 벽을 뚫지 않고 앞으로 당겨진다.

## 6 상점 퇴장 후 이전 상점 화면 깜빡임

- [ ] 미로 상점에서 나가기 후 다음 선택지가 뜰 때 이전 상점 창이 보이지 않는다.
- [ ] 상점 진입·선택지·지도 화면 전환이 끊기거나 비어 보이지 않는다.
- [ ] 다음 전투의 계획 화면이 열릴 때 이전 전투 화면이, 다음 결과 화면이 열릴 때 이전 결과 화면이 비쳐 보이지 않는다.
- [ ] 메인 메뉴 화면 전환(새 게임·옵션·백과사전 등)에서 이전 화면이 겹쳐 보이지 않는다. 교차 페이드가 사라져 즉시 바뀐다.

## 7 전투 직전 프레임 드랍

- [ ] PvE·PvP 전투 직전(문을 지나 전장으로 넘어갈 때) 화면이 멈추는 느낌이 줄었다. 에디터 PIE는 Niagara 셰이더 컴파일 대기가 남을 수 있으므로 Standalone 또는 패키지 실행으로 비교한다.
- [ ] 전투 시작 후 첫 스킬 이펙트·사운드가 정상 재생된다.

## 8 힘·민첩·지능 재도입

- [ ] 캐릭터 생성 화면에 직업별 힘·민첩·지능이 보인다(전사 10/5/1, 마법사 1/5/10, 궁수 5/7/4, 도적 5/10/1).
- [ ] 전사·도적의 근접 공격과 마법사의 지팡이 스킬 피해가 힘·지능만큼 늘었고, 활·회복·보호막·상태이상 피해는 그대로다.
- [ ] 속도 차 1당 시작 지연 1초가 적용되어 민첩 5인 전사·마법사가 도적보다 5초 늦게 행동하고, 느린 몬스터의 대기 시간이 체감상 과하지 않은지 확인한다.
- [ ] 전투 중 체크포인트 복구와 이어하기 후에도 같은 피해가 나온다.
