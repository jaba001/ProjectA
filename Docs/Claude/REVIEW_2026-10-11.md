# 2026-10-11 전체 리뷰

## 1 범위와 한계

- 런타임 C++ 약 4.5만 줄 중 전투 라운드·저장·네트워크 RPC·데이터 로딩·GAS를 중심으로 읽었다. 설정·`AGENTS.md`·Docs 구조와 런타임·에디터 테스트의 문자열 의존을 확인했다.
- 에디터 에셋 라이브러리·Python 스크립트·Blueprint·에셋은 검토하지 않았다.
- 리뷰 시점에는 컴파일·PIE·자동화 테스트를 실행하지 않았다. 이후 수정 결과의 검증 상태는 [HANDOFF](HANDOFF.md)를 따른다.

## 2 강점

- 클라이언트 요청을 서버가 `CombatId`·라운드·Revision·원래 소유권으로 다시 검증한다. 구매·장비·보상도 `ResolveRunParticipant`를 거친다.
- 저장은 임시 파일 쓰기→재읽기 비교→`MoveFileExW` 교체, 실패 시 이전 상태 복원, lease·epoch 기반 중복 실행 방지로 구성되어 있다.
- 전투 시뮬레이션은 고정 간격과 누적 시간 보존을 사용하며 보호막 흡수·NaN 방어가 일관된다.
- 문서가 구현·컴파일·미검증 상태를 구분한다.
