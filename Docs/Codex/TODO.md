권장: 선택 1. 추가 AI의 비전투 장비·보상 결정권을 정하기 전에 원래 소유권과 2/4인 흐름을 확인할 수 있다. 선택 후 생성·편성·저장 UI를 연결한다. 수용 조건은 각 인간의 자기 캐릭터 조작과 초기 소유권 보존이며 참가 번호 1·2·3·4와 캐릭터 슬롯을 혼동하지 않는 것이다. Host 승계·AI 전환·복귀로 소유권을 이전하지 않는다.

## 4 온라인 협동과 경쟁

**T14는 Steam·PlayFab 서비스 준비와 실제 연동이 필요하다.** 계정·서비스 ID·비용 조건과 온라인 권위 정책이 준비되지 않은 항목은 외부 준비/결정 대기다. 로컬 코드·문서 점검은 독립적으로 진행하되 서비스 활성화·실제 연결 완료로 기록하지 않는다. 비용·소유권·저장 권위의 기준은 [멀티플레이 계약](MULTIPLAYER.md)을 따른다.

권장: 선택 1. Listen Server·Steam P2P 전투를 유지하며 중앙 검증 호출을 줄인다. 선택 후 서버 재현 가능한 판정 범위·실패/이탈·미확정 Attempt 처리와 필요한 무료 계산 범위를 확인한다. 수용 조건은 동일 Attempt의 새 요청 ID 제출도 중복 반영하지 않고, Ready 강제 종료 후 같은 확정 명령·시드로 복구하며, 변조·오래된 버전·미검증 결과가 정산에 진입하지 않는 것이다. 고의 이탈의 추가 랭크 제재는 별도 선택 전 적용하지 않는다.
