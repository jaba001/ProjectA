이번 촬영의 숄더 화면에는 캐릭터가 보이지 않고 카메라 위치가 (0, 0, 0)으로 기록된 사례가 있습니다. 실제 중 난이도의 전술 화면에는 회색 체크무늬 바닥이 보입니다. 독립 석조 던전 화면과 함께 비교할 수 있습니다. 화면 보정이나 에셋 수정 없이 현재 출력을 그대로 보존했습니다. ‘행동 후 화면’은 전술 카메라 복귀 성공을 뜻하지 않습니다. 이 기록만으로 시각 품질이나 전체 게임 동작 검증을 완료하지 않습니다.

1. 실제 PvE 전투

새 게임에서 기본 캐릭터 4명과 직접 조작 캐릭터 1명을 구성하고, 실제 인카운터의 난이도를 선택해 촬영했습니다. 세 난이도 모두 통합 Gameplay 맵에서 실행되며 적용된 배경이 다릅니다.

2. 독립 환경맵 14종

원본 환경맵의 비교용 전경입니다. 기존 디버그 구성인 아군 1명·적 1명, 각각 HP 10,000을 사용했습니다. 실제 PvE 몬스터 구성이나 난이도 수치와 구분해 보십시오.

3. 시작 메뉴와 개발용 전투맵

Core/MainMenu와 Development/DebugCombat의 현재 화면입니다.

촬영 범위와 원본 확인
  • 실제 엔진 화면을 새로 촬영했으며, 이 갤러리는 PNG를 재인코딩·크롭·리터칭하지 않습니다. 화면상의 미리보기 크기만 CSS로 조절합니다.
  • PNG 헤더, 1280 × 720 해상도, Pillow 파일 검증, 원본/복사본 SHA-256 일치를 확인합니다. 각 파일의 해시와 출처는 manifest.json에 있습니다.
  • 프로젝트 전용 LEVEL 폴더의 .umap 17개를 모두 포함합니다. 외부 라이브러리 데모맵 전체를 뜻하지 않습니다.
  • PvE 진행은 UI 버튼 델리게이트와 공개 컨트롤러 요청을 통한 자동화입니다. 사람이 마우스로 플레이한 검수와 구분합니다.
  • 소스 콘텐츠를 변경하지 않는 촬영이며, 촬영용 저장 경로를 분리합니다. 기본 코드 기준은 242a12cb입니다.
  • 이 스크린샷은 시각적 판단 자료입니다. 밸런스, 협동, Continue, 모든 카메라 예외 상황의 성공 근거로 확대하지 않습니다.
